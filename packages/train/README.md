# veg-train

Training command for the experimental Veyrian Execution Generator.
Automatically installs the matching `veg-core` version.

    python -m pip install veg-train
    veg-train --help

Source and documentation: https://github.com/A-Proof/veg

Provide your own training and validation byte corpora. Delta memory remains
experimental; no frontier-quality or improved data-efficiency claim is made.
